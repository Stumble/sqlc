# wicked-sqlc v2.4.1

This patch release publishes prebuilt binaries for the first time and updates
Go and dependencies flagged by govulncheck. Generated code is the same as v2.4.0
apart from the version comment.

## Changes

- Binaries for Linux (amd64, arm64; static, any distribution), macOS (amd64,
  arm64; 12 or later) and Windows (amd64), with `checksums.txt` and build
  provenance.
- `scripts/install.sh` installs a release after checking its SHA-256.
- Go 1.26.10 (was 1.26.8), golang.org/x/net v0.60.0, golang.org/x/text v0.42.0
  and google.golang.org/grpc v1.83.1 fix 14 vulnerabilities govulncheck reports
  as reachable in v2.4.0.

## Upgrade

```sh
curl -fsSL https://raw.githubusercontent.com/Stumble/sqlc/main/scripts/install.sh | sh -s -- v2.4.1
sqlc version
# v2.4.1-wicked-fork
```

Set `SQLC_SHA256` to the archive's value in `checksums.txt` to accept only that
archive. `gh attestation verify <archive> -R Stumble/sqlc` checks that an
archive was built by this repository's release workflow. On Windows, download
`sqlc_2.4.1_windows_amd64.zip` from the release. Building from source with
`make install` now requires Go 1.26.10.

Regenerate with `sqlc generate`; only the version comments change.

See the [guide](https://github.com/Stumble/sqlc/blob/main/GUIDE.md#install).
